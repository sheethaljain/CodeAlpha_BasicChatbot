# CodeAlpha Basic Chatbot

A simple rule-based chatbot developed using Python as part of my CodeAlpha Python Programming Internship.

## Features

- Responds to greetings
- Answers predefined questions
- Provides basic help
- Handles unknown messages
- Runs until the user enters "bye"

## Technologies Used

- Python 3
- Visual Studio Code

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run:

   python chatbot.py

## Concepts Practiced

- Functions
- Conditional statements
- Loops
- String manipulation
- User input and output
